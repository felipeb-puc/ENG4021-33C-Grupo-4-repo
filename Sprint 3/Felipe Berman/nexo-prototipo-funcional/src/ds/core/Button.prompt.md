The primary pill CTA — always fully rounded, semibold, with an optional trailing arrow.

```jsx
<Button icon="arrow-right">Ver vagas</Button>
<Button variant="outline" size="sm">Filtros</Button>
<Button variant="inverse" icon="arrow-right">Sobre nós</Button>
```

Variants: `primary` (green-600 fill, default), `dark` (green-900 — use on light green sections), `secondary` (green-50 tint), `outline`, `ghost`, `inverse` (white on dark green bands). Sizes sm/md/lg map to the control-height tokens. Press state shrinks to 0.975; hover darkens one step.
