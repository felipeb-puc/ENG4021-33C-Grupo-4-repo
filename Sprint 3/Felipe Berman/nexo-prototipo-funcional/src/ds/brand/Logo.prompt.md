# Logo

```jsx
<Logo />                       // default lockup, light surfaces
<Logo size={34} />             // larger
<Logo inverse />               // on --green-900
<Logo mark size={28} />        // rings only — favicon, avatar, tight nav
```

Rules: never change the ring colours or their order, never add a new symbol,
never set the lockup below 18px cap height (use `mark` instead).
