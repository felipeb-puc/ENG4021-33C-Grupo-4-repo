# Protótipo funcional do NEXO

**Link:** https://nexo-zeta-cyan.vercel.app

O site roda direto no navegador, sem instalação. Os dados ficam salvos no armazenamento local de cada navegador: quem abre o link começa do mesmo ponto de partida (o banco de demonstração), e o que for feito ali (candidatura, publicação de vaga, aprovação de conta) fica só naquele navegador.
